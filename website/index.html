Good to know

Before you plug in.

freqx is intentionally simple, but audio routing can be unfamiliar the first time.

Read the project docs ↗
What does freqx run on?

freqx 1.6.0 is a desktop app for Windows 10 and Windows 11.

Do I need an account?

No. Your setup and imported audio stay local to your computer.

Can I use my own sound files?

Yes. The desktop app is designed around importing and organizing audio files you already have permission to use.

Is the project open source?

Yes. The source, releases, and issue tracker are available in the public GitHub repository.
